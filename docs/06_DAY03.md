## 📚 ICD v1.0 규격 요약

### 패킷 구조

```
┌─────────────────────────────────────────────────────────────┐
│                    ICD v1.0 메시지 구조                      │
├──────────┬──────────┬──────────┬────────────┬───────┬───────┤
│TimeStamp │  MSG ID  │ Reserved │ DataLength │ Data  │Chksum │
│ (4 bytes)│ (4 bytes)│ (2 bytes)│ (2 bytes)  │(가변) │(2 B)  │
├──────────┼──────────┼──────────┼────────────┼───────┼───────┤
│ 0-3      │ 4-7      │ 8-9      │ 10-11      │ 12-N  │ N+1-2 │
└──────────┴──────────┴──────────┴────────────┴───────┴───────┘
```

**총 길이**: `12 (헤더) + DataLength + 2 (체크섬)` bytes

### 헤더 구조 (12 바이트)

| 오프셋 | 크기 | 필드명 | 설명 |
|--------|------|--------|------|
| 0 | 4 | TimeStamp | 타임스탬프 (하위 1바이트 = 시퀀스) |
| 4 | 1 | Source ID | 송신 장비 ID |
| 5 | 1 | Dest ID | 수신 장비 ID |
| 6 | 1 | MSG Code | 메시지 코드 (0x01 = 상태보고) |
| 7 | 1 | ACK Flag | 응답 코드 |
| 8 | 2 | Reserved | 예약 (0x0000) |
| 10 | 2 | Data Length | 데이터 영역 길이 |

### 상태보고 페이로드 (MSG Code = 0x01)

| 오프셋 | 크기 | 필드명 | 설명 |
|--------|------|--------|------|
| 0-1 | 2 | 장치 연결 상태 | bits 9..0 = 10개 장치 연결 여부 |
| 2 | 1 | VIC 운용 상태 | bits 7..5=모드, 3..2=권한, 1..0=주행 |
| 3-4 | 2 | 비상정지 원인 | bits 15..6 = 10개 비상정지 원인 |

### 체크섬 계산

```
Checksum = (체크섬 필드 제외 모든 바이트 합) & 0xFFFF
```

### 3. `ugv_mon/parser/icd_parser.py`

**역할**: ICD v1.0 패킷 파싱 메인 클래스

**핵심 메서드**:
- `parse(data: bytes) -> ParseResult`: 패킷 전체 파싱
- `_parse_header(data: bytes) -> ICDHeader`: 헤더 파싱
- `_verify_checksum(data: bytes) -> bool`: 체크섬 검증
- `_parse_status_payload(payload: bytes) -> StatusPayload`: 상태보고 페이로드 파싱

**파싱 플로우**:
1. 최소 길이 검증 (14 bytes = 헤더 12 + 체크섬 2)
2. 헤더 파싱 (12 bytes)
3. 길이 검증 (실제 길이 vs DataLength 필드)
4. 체크섬 검증 (모든 바이트 합 & 0xFFFF)
5. 페이로드 파싱 (상태보고인 경우)

### 2. 단위 테스트 (테스트 패킷 생성)

```bash
python3 -c "
from ugv_mon.parser import ICDParser
import struct

# 테스트 패킷 생성 (실제 ICD 규격 준수)
timestamp = 12345678
sequence = 42
source_id = 0xB1
dest_id = 0xA2
msg_code = 0x01
ack_flag = 0xFF
reserved = 0
data_length = 5

# 헤더
header = struct.pack('<I', timestamp)
header += bytes([source_id, dest_id, msg_code, ack_flag])
header += struct.pack('<H', reserved)
header += struct.pack('<H', data_length)

# 페이로드 (상태보고)
device_presence = 0x03FF  # 모든 장치 연결
vic_state = 0b01001001   # Mode=2, Authority=2, Driving=1
emergency = 0x0000

payload = struct.pack('<H', device_presence)
payload += bytes([vic_state])
payload += struct.pack('<H', emergency)

# 체크섬
data_without_checksum = header + payload
checksum = sum(data_without_checksum) & 0xFFFF
packet = data_without_checksum + struct.pack('<H', checksum)

# 파싱
parser = ICDParser()
result = parser.parse(packet)

print(f'Parse success: {result.success}')
print(f'Checksum OK: {result.checksum_ok}')
if result.header:
    print(f'Sequence: {result.header.sequence}')
    print(f'MSG Code: 0x{result.header.msg_code:02X}')
    print(f'Data Length: {result.header.data_length}')
if result.payload:
    print(f'Operation Mode: {result.payload.operation_mode_label}')
    print(f'Authority: {result.payload.authority_label}')
    print(f'Driving State: {result.payload.driving_state_label}')
    devices = [k for k, v in result.payload.devices.items() if v]
    print(f'Connected Devices: {devices}')
"
```

```

Data Length: 5

Driving State: 원격 (REMOTE)
Connected Devices: ['VIC', 'RDC', 'ADC', 'FCAM', 'RCAM', 'ACAM', 'SCS', 'DIP', 'TCC', 'TM']
```

## 📝 코드 설명 (핵심 개념)

### Q: 왜 struct.unpack을 사용하나요?

**A**: Python의 바이너리 언패킹 표준 라이브러리입니다.
- `<H`: Little Endian unsigned short (2 bytes)
- `<I`: Little Endian unsigned int (4 bytes)
- 바이트 배열을 정수로 변환하는 가장 효율적인 방법

### Q: 체크섬 검증을 왜 먼저 하나요?

**A**: 손상된 패킷을 조기에 걸러내기 위함입니다.
- 체크섬이 틀리면 나머지 필드도 신뢰할 수 없습니다
- 불필요한 파싱 작업을 방지합니다

### Q: 비트 추출은 어떻게 하나요?

**A**: 비트 시프트와 마스킹을 사용합니다.
- `(byte >> 5) & 0x07`: 상위 3비트 추출 (운용 모드)
- `(byte >> 2) & 0x03`: 중간 2비트 추출 (권한)
- `byte & 0x03`: 하위 2비트 추출 (주행 상태)

### Q: 왜 딕셔너리로 라벨을 정의하나요?

**A**: O(1) 조회 성능과 유지보수 용이성.
- if-else 체인보다 빠르고 명확합니다
- 새로운 모드 추가 시 딕셔너리만 수정하면 됩니다

## ⚠️ 주의사항

### 페이로드 오프셋

실제 ICD 규격에 따라 페이로드 오프셋은 다음과 같습니다:
- `[0:2]`: 장치 연결 상태 (2 bytes)
- `[2]`: VIC 운용 상태 (1 byte)
- `[3:5]`: 비상정지 원인 (2 bytes)

**문서의 오프셋과 다를 수 있으니 실제 코드를 확인하세요.**

### 체크섬 계산

체크섬은 **체크섬 필드를 제외한** 모든 바이트의 합입니다:
```python
checksum = sum(data_without_checksum) & 0xFFFF
```

### 시퀀스 번호 롤오버

시퀀스 번호는 8비트 (0-255)이므로 255 다음에는 0으로 순환합니다.
패킷 손실 추정 시 롤오버를 고려해야 합니다.
