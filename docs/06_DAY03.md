## 📚 ICD v1.0 규격 요약

### 패킷 구조 (총 99+ 바이트)

```
┌─────────────────────────────────────────────────────────────┐
│                      ICD 패킷 구조                          │
├─────────────┬───────────────────────────────────────────────┤
│   Header    │ 12 bytes (고정)                               │
├─────────────┼───────────────────────────────────────────────┤
│   Data      │ N bytes (가변, Data Length 필드에 명시)       │
├─────────────┼───────────────────────────────────────────────┤
│  Checksum   │ 2 bytes (고정)                                │
└─────────────┴───────────────────────────────────────────────┘
```

### 헤더 구조 (12 바이트)

| 오프셋 | 크기 | 필드명 | 설명 |
|--------|------|--------|------|
| 0 | 4 | TimeStamp | 타임스탬프 (하위 1바이트 = 시퀀스) |
| 4 | 1 | Source ID | 송신 장비 ID |
| 5 | 1 | Dest ID | 수신 장비 ID |
| 6 | 1 | MSG Code | 메시지 코드 |
| 7 | 1 | ACK Code | 응답 코드 |
| 8 | 2 | Reserved | 예약 (0x0000) |
| 10 | 2 | Data Length | 데이터 영역 길이 |

### 상태보고 메시지 페이로드 (MSG Code = 0x01, 87 바이트)

| 오프셋 | 크기 | 필드명 | 설명 |
|--------|------|--------|------|
| 0 | 1 | 운용상태 바이트 | bits 7..5=모드, 3..2=권한, 1..0=주행상태 |
| 6 | 2 | 장치 현시 워드 | bits 9..0 = 10개 장치 연결 상태 |
| 20 | 2 | 비상정지 원인 워드 | bits 9..0 = 10개 비상정지 원인 |

### 체크섬 계산

```
Checksum = (Header + Data 전체 바이트 합계) & 0xFFFF
```

### 3. `ugv_mon/parser/models.py`

> 파싱 결과를 담는 데이터 클래스들입니다.

```python
"""
ICD Parser Data Models.

파싱 결과를 저장하는 데이터 클래스를 정의합니다.
모든 필드는 ICD v1.0 규격을 따릅니다.

Endianness: Little Endian (모든 멀티바이트 필드)
"""

from dataclasses import dataclass, field
from typing import Dict, Optional
from enum import IntEnum


class OperationModeCode(IntEnum):
    """
    운용 모드 코드 (bits 7..5).
    
    ICD 규격의 운용상태 바이트 상위 3비트.
    """
    PREP = 0b000              # 준비
    TRANSITION = 0b001        # 전환
    UNMANNED_DRIVING = 0b010  # 무인주행
    UNMANNED_FIRING = 0b011   # 무인사격
    EMERGENCY_STOP = 0b100    # 비상정지


class AuthorityCode(IntEnum):
    """
    운용 권한 코드 (bits 3..2).
    
    ICD 규격의 운용상태 바이트 중간 2비트.
    """
    RELEASED = 0b00           # 해제됨
    OCS_ACQUIRED = 0b01       # OCS 획득
    NEAR_CONTROLLER = 0b10    # 근거리조종기


class DrivingStateCode(IntEnum):
    """
    주행 상태 코드 (bits 1..0).
    
    ICD 규격의 운용상태 바이트 하위 2비트.
    """
    STANDBY = 0b00            # 대기
    REMOTE = 0b01             # 원격
    PLATOONING = 0b10         # 종속주행(platooning)
    AUTONOMOUS = 0b11         # 자율주행


@dataclass
class ICDHeader:
    """
    ICD 패킷 헤더 (12 바이트).
    
    모든 ICD 패킷의 공통 헤더 구조입니다.
    
    Attributes:
        timestamp: 4바이트 타임스탬프 (원본 값)
        sequence: 시퀀스 번호 (timestamp 하위 1바이트)
        source_id: 송신 장비 ID
        dest_id: 수신 장비 ID
        msg_code: 메시지 코드 (0x01 = 상태보고)
        ack_code: 응답 코드
        reserved: 예약 필드 (보통 0)
        data_length: 데이터 영역 길이
    """
    timestamp: int           # 4바이트 원본
    sequence: int            # 하위 1바이트 (0-255)
    source_id: int           # 송신 장비 ID
    dest_id: int             # 수신 장비 ID
    msg_code: int            # 메시지 코드
    ack_code: int            # 응답 코드
    reserved: int            # 예약 (2바이트)
    data_length: int         # 데이터 길이
    
    def to_dict(self) -> Dict:
        """딕셔너리 변환 (디버깅/로깅용)."""
        return {
            "timestamp": self.timestamp,
            "sequence": self.sequence,
            "source_id": f"0x{self.source_id:02X}",
            "dest_id": f"0x{self.dest_id:02X}",
            "msg_code": f"0x{self.msg_code:02X}",
            "ack_code": self.ack_code,
            "data_length": self.data_length,
        }


@dataclass
class StatusReportPayload:
    """
    상태보고 메시지 페이로드 (MSG Code = 0x01).
    
    VIC가 OCS에게 전송하는 상태보고 메시지의 데이터 영역입니다.
    
    Attributes:
        operation_mode: 운용 모드 (한글 문자열)
        authority: 운용 권한 (한글 문자열)
        driving_state: 주행 상태 (한글 문자열)
        device_presence: 장치 연결 상태 딕셔너리
        emergency_causes: 비상정지 원인 딕셔너리
        raw_state_byte: 원본 운용상태 바이트
        raw_device_word: 원본 장치현시 워드
        raw_emergency_word: 원본 비상정지 워드
    """
    # 파싱된 값 (한글 문자열)
    operation_mode: str
    authority: str
    driving_state: str
    
    # 장치 연결 상태 (딕셔너리)
    device_presence: Dict[str, bool] = field(default_factory=dict)
    
    # 비상정지 원인 (딕셔너리)
    emergency_causes: Dict[str, bool] = field(default_factory=dict)
    
    # 원본 값 (디버깅용)
    raw_state_byte: int = 0
    raw_device_word: int = 0
    raw_emergency_word: int = 0
    
    def to_dict(self) -> Dict:
        """딕셔너리 변환 (UI 전달용)."""
        return {
            "operationalMode": self.operation_mode,
            "operationalAuthority": self.authority,
            "drivingState": self.driving_state,
            "devices": self.device_presence,
            "emergencyStatus": self.emergency_causes,
        }


@dataclass
class ParseResult:
    """
    ICD 파싱 결과.
    
    파싱 성공/실패 여부와 함께 파싱된 데이터를 담습니다.
    
    Attributes:
        success: 파싱 성공 여부
        header: 파싱된 헤더 (실패 시 None)
        payload: 파싱된 페이로드 (상태보고가 아니면 None)
        checksum_ok: 체크섬 검증 통과 여부
        error: 에러 메시지 (실패 시)
        raw_data: 원본 바이트 데이터
    """
    success: bool
    header: Optional[ICDHeader] = None
    payload: Optional[StatusReportPayload] = None
    checksum_ok: bool = False
    error: str = ""
    raw_data: bytes = b""
    
    def is_status_report(self) -> bool:
        """
        상태보고 메시지인지 확인.
        
        Returns:
            MSG Code가 0x01이면 True
        """
        if self.header is None:
            return False
        return self.header.msg_code == 0x01
    
    def to_dict(self) -> Dict:
        """딕셔너리 변환."""
        result = {
            "success": self.success,
            "checksum_ok": self.checksum_ok,
            "error": self.error,
        }
        if self.header:
            result["header"] = self.header.to_dict()
        if self.payload:
            result["payload"] = self.payload.to_dict()
        return result
```

| `AuthorityCode` | 권한 비트 상수 |
| `DrivingStateCode` | 주행 상태 비트 상수 |

### 4. `ugv_mon/parser/icd_parser.py`

> ICD v1.0 패킷을 파싱하는 핵심 모듈입니다.

```python
"""
ICD v1.0 Parser Module.

VIC→OCS 패킷의 헤더와 페이로드를 파싱합니다.

파싱 순서:
1. 헤더 파싱 (12바이트)
2. 체크섬 검증
3. 페이로드 파싱 (MSG Code에 따라)

특징:
- struct 모듈로 바이너리 언패킹
- Little Endian 처리
- 상세한 에러 메시지
"""

import struct
import logging
from typing import Dict, Optional, Tuple

from ..config import config
from .models import (
    ParseResult,
    ICDHeader,
    StatusReportPayload,
    OperationModeCode,
    AuthorityCode,
    DrivingStateCode,
)

# 로거 설정
logger = logging.getLogger(__name__)


class ICDParser:
    """
    ICD v1.0 패킷 파서.
    
    바이너리 패킷 데이터를 파싱하여 구조화된 결과를 반환합니다.
    
    Usage:
        parser = ICDParser()
        result = parser.parse(raw_bytes)
        
        if result.success and result.checksum_ok:
            print(f"Sequence: {result.header.sequence}")
    """
    
    # 헤더 구조: <IBBBBHH (Little Endian)
    # I: timestamp (4바이트, unsigned int)
    # B: source_id (1바이트, unsigned char)
    # B: dest_id (1바이트)
    # B: msg_code (1바이트)
    # B: ack_code (1바이트)
    # H: reserved (2바이트, unsigned short)
    # H: data_length (2바이트)
    HEADER_FORMAT = "<IBBBBHH"
    HEADER_SIZE = 12  # struct.calcsize(HEADER_FORMAT)
    
    # 체크섬 크기
    CHECKSUM_SIZE = 2
    
    # 상태보고 MSG Code
    STATUS_REPORT_MSG_CODE = 0x01
    STATUS_REPORT_DATA_SIZE = 87
    
    # 운용 모드 매핑 (한글)
    MODE_NAMES = {
        OperationModeCode.PREP: "준비 (PREP)",
        OperationModeCode.TRANSITION: "전환 (TRANSITION)",
        OperationModeCode.UNMANNED_DRIVING: "무인주행 (UNMANNED)",
        OperationModeCode.UNMANNED_FIRING: "무인사격 (FIRING)",
        OperationModeCode.EMERGENCY_STOP: "비상정지 (E-STOP)",
    }
    
    # 권한 매핑 (한글)
    AUTHORITY_NAMES = {
        AuthorityCode.RELEASED: "해제됨 (RELEASED)",
        AuthorityCode.OCS_ACQUIRED: "OCS(운용통제기)",
        AuthorityCode.NEAR_CONTROLLER: "근거리조종기",
    }
    
    # 주행 상태 매핑 (한글)
    DRIVING_STATE_NAMES = {
        DrivingStateCode.STANDBY: "대기 (STANDBY)",
        DrivingStateCode.REMOTE: "원격 (REMOTE)",
        DrivingStateCode.PLATOONING: "종속주행 (PLATOONING)",
        DrivingStateCode.AUTONOMOUS: "자율 (AUTONOMOUS)",
    }
    
    # 장치 목록 (bit 위치 → 이름)
    DEVICE_NAMES = [
        ("VIC", 0),       # bit 0
        ("RDC", 1),       # bit 1
        ("ADC", 2),       # bit 2
        ("FCAM", 3),      # bit 3
        ("RCAM", 4),      # bit 4
        ("ACAM", 5),      # bit 5 - 보조 영상처리기
        ("SCS", 6),       # bit 6
        ("DIP", 7),       # bit 7
        ("TCC", 8),       # bit 8
        ("TM", 9),        # bit 9
    ]
    
    # 비상정지 원인 목록 (bit 위치 → 이름)
    EMERGENCY_NAMES = [
        ("통신 두절", 0),
        ("장비고장(주행)", 1),
        ("장비고장(동력계)", 2),
        ("신호단절(주행)", 3),
        ("신호단절(자율)", 4),
        ("신호단절(항법)", 5),
        ("신호단절(동력계)", 6),
        ("신호단절(통신)", 7),
        ("수동정지(운용통제장치)", 8),
        ("수동정지(근거리조종기)", 9),
    ]
    
    def __init__(self):
        """ICDParser 초기화."""
        logger.info("ICDParser initialized")
    
    def parse(self, data: bytes) -> ParseResult:
        """
        패킷 전체 파싱.
        
        헤더 → 체크섬 → 페이로드 순서로 파싱합니다.
        
        Args:
            data: 원시 패킷 바이트 데이터
            
        Returns:
            ParseResult: 파싱 결과
        """
        # 최소 길이 검사 (헤더 + 체크섬)
        min_length = self.HEADER_SIZE + self.CHECKSUM_SIZE
        if len(data) < min_length:
            return ParseResult(
                success=False,
                error=f"패킷 너무 짧음: {len(data)} < {min_length}",
                raw_data=data,
            )
        
        # 1. 헤더 파싱
        header = self._parse_header(data[:self.HEADER_SIZE])
        if header is None:
            return ParseResult(
                success=False,
                error="헤더 파싱 실패",
                raw_data=data,
            )
        
        # 2. 패킷 길이 검증
        expected_length = self.HEADER_SIZE + header.data_length + self.CHECKSUM_SIZE
        if len(data) < expected_length:
            return ParseResult(
                success=False,
                header=header,
                error=f"데이터 길이 불일치: {len(data)} < {expected_length}",
                raw_data=data,
            )
        
        # 3. 체크섬 검증
        checksum_ok = self._verify_checksum(data[:expected_length])
        
        # 4. 페이로드 파싱 (상태보고 메시지인 경우)
        payload = None
        if header.msg_code == self.STATUS_REPORT_MSG_CODE:
            payload_start = self.HEADER_SIZE
            payload_end = self.HEADER_SIZE + header.data_length
            payload_data = data[payload_start:payload_end]
            payload = self._parse_status_report(payload_data)
        
        return ParseResult(
            success=True,
            header=header,
            payload=payload,
            checksum_ok=checksum_ok,
            raw_data=data[:expected_length],
        )
    
    def _parse_header(self, data: bytes) -> Optional[ICDHeader]:
        """
        헤더 파싱 (12 바이트).
        
        struct.unpack을 사용하여 바이너리 데이터를 언패킹합니다.
        
        Args:
            data: 헤더 바이트 (12바이트)
            
        Returns:
            ICDHeader 또는 None (실패 시)
        """
        try:
            # struct.unpack: 바이너리 → Python 값
            # < : Little Endian
            # I : unsigned int (4바이트) → timestamp
            # B : unsigned char (1바이트) → source_id, dest_id, msg_code, ack_code
            # H : unsigned short (2바이트) → reserved, data_length
            unpacked = struct.unpack(self.HEADER_FORMAT, data)
            
            timestamp = unpacked[0]
            source_id = unpacked[1]
            dest_id = unpacked[2]
            msg_code = unpacked[3]
            ack_code = unpacked[4]
            reserved = unpacked[5]
            data_length = unpacked[6]
            
            # 시퀀스 번호: timestamp의 하위 1바이트
            sequence = timestamp & 0xFF
            
            return ICDHeader(
                timestamp=timestamp,
                sequence=sequence,
                source_id=source_id,
                dest_id=dest_id,
                msg_code=msg_code,
                ack_code=ack_code,
                reserved=reserved,
                data_length=data_length,
            )
            
        except struct.error as e:
            logger.error(f"Header unpack error: {e}")
            return None
    
    def _verify_checksum(self, data: bytes) -> bool:
        """
        체크섬 검증.
        
        ICD 규격: 체크섬 = (모든 바이트 합) & 0xFFFF
        
        Args:
            data: 전체 패킷 (헤더 + 데이터 + 체크섬)
            
        Returns:
            체크섬 일치 여부
        """
        if len(data) < self.CHECKSUM_SIZE:
            return False
        
        # 체크섬 필드 위치: 마지막 2바이트
        checksum_start = len(data) - self.CHECKSUM_SIZE
        
        # 체크섬 제외한 부분의 바이트 합
        calculated = sum(data[:checksum_start]) & 0xFFFF
        
        # 저장된 체크섬 읽기 (Little Endian)
        stored = struct.unpack("<H", data[checksum_start:])[0]
        
        if calculated != stored:
            logger.debug(
                f"Checksum mismatch: calculated=0x{calculated:04X}, "
                f"stored=0x{stored:04X}"
            )
            return False
        
        return True
    
    def _parse_status_report(self, data: bytes) -> Optional[StatusReportPayload]:
        """
        상태보고 페이로드 파싱.
        
        상태보고 메시지(MSG Code=0x01)의 데이터 영역을 파싱합니다.
        
        Args:
            data: 페이로드 바이트 데이터
            
        Returns:
            StatusReportPayload 또는 None
        """
        if len(data) < 21:  # 최소 필요 크기 (운용상태 + 장치현시 + 비상정지)
            logger.warning(f"Status report too short: {len(data)} bytes")
            return None
        
        try:
            # 오프셋 0: 운용상태 바이트
            state_byte = data[0]
            
            # 오프셋 6-7: 장치 현시 워드 (2바이트, Little Endian)
            device_word = struct.unpack("<H", data[6:8])[0]
            
            # 오프셋 20-21: 비상정지 원인 워드 (2바이트, Little Endian)
            emergency_word = struct.unpack("<H", data[20:22])[0]
            
            # 비트 필드 추출
            operation_mode = self._extract_operation_mode(state_byte)
            authority = self._extract_authority(state_byte)
            driving_state = self._extract_driving_state(state_byte)
            device_presence = self._extract_device_presence(device_word)
            emergency_causes = self._extract_emergency_causes(emergency_word)
            
            return StatusReportPayload(
                operation_mode=operation_mode,
                authority=authority,
                driving_state=driving_state,
                device_presence=device_presence,
                emergency_causes=emergency_causes,
                raw_state_byte=state_byte,
                raw_device_word=device_word,
                raw_emergency_word=emergency_word,
            )
            
        except Exception as e:
            logger.error(f"Status report parse error: {e}")
            return None
    
    def _extract_operation_mode(self, state_byte: int) -> str:
        """
        운용 모드 추출 (bits 7..5).
        
        Args:
            state_byte: 운용상태 바이트
            
        Returns:
            운용 모드 한글 문자열
        """
        # 상위 3비트 추출: (byte >> 5) & 0b111
        mode_bits = (state_byte >> 5) & 0b111
        
        try:
            mode = OperationModeCode(mode_bits)
            return self.MODE_NAMES.get(mode, f"알 수 없음 ({mode_bits})")
        except ValueError:
            return f"알 수 없음 ({mode_bits})"
    
    def _extract_authority(self, state_byte: int) -> str:
        """
        운용 권한 추출 (bits 3..2).
        
        Args:
            state_byte: 운용상태 바이트
            
        Returns:
            권한 한글 문자열
        """
        # bits 3..2 추출: (byte >> 2) & 0b11
        auth_bits = (state_byte >> 2) & 0b11
        
        try:
            auth = AuthorityCode(auth_bits)
            return self.AUTHORITY_NAMES.get(auth, f"알 수 없음 ({auth_bits})")
        except ValueError:
            return f"알 수 없음 ({auth_bits})"
    
    def _extract_driving_state(self, state_byte: int) -> str:
        """
        주행 상태 추출 (bits 1..0).
        
        Args:
            state_byte: 운용상태 바이트
            
        Returns:
            주행 상태 한글 문자열
        """
        # 하위 2비트 추출: byte & 0b11
        drive_bits = state_byte & 0b11
        
        try:
            drive = DrivingStateCode(drive_bits)
            return self.DRIVING_STATE_NAMES.get(drive, f"알 수 없음 ({drive_bits})")
        except ValueError:
            return f"알 수 없음 ({drive_bits})"
    
    def _extract_device_presence(self, device_word: int) -> Dict[str, bool]:
        """
        장치 연결 상태 추출 (bits 9..0).
        
        Args:
            device_word: 장치 현시 워드 (2바이트)
            
        Returns:
            장치명 → 연결 여부 딕셔너리
        """
        result = {}
        for name, bit_pos in self.DEVICE_NAMES:
            # 비트 추출: (word >> bit_pos) & 1
            connected = bool((device_word >> bit_pos) & 1)
            result[name] = connected
        return result
    
    def _extract_emergency_causes(self, emergency_word: int) -> Dict[str, bool]:
        """
        비상정지 원인 추출 (bits 9..0).
        
        Args:
            emergency_word: 비상정지 원인 워드 (2바이트)
            
        Returns:
            원인명 → 활성 여부 딕셔너리
        """
        result = {}
        for name, bit_pos in self.EMERGENCY_NAMES:
            # 비트 추출: (word >> bit_pos) & 1
            active = bool((emergency_word >> bit_pos) & 1)
            result[name] = active
        return result
```

**코드 설명 (핵심 개념)**:

| 개념 | 설명 |
|------|------|
| `struct.unpack("<IBBBBHH", data)` | Little Endian으로 바이너리 언패킹 |
| `<` | Little Endian 지정자 |
| `I` | unsigned int (4바이트) |
| `B` | unsigned char (1바이트) |
| `H` | unsigned short (2바이트) |
| `(byte >> 5) & 0b111` | 상위 3비트 추출 (비트 시프트 + 마스킹) |
| `sum(data) & 0xFFFF` | 체크섬 계산 (16비트 마스킹) |

from ugv_mon.parser import ICDParser

# 테스트 패킷 생성 (실제 ICD 규격 준수)
def create_test_packet():
    import struct
    
    # 헤더 (12바이트)
    timestamp = 0x12345678  # 시퀀스 = 0x78
    source_id = 0x01        # VIC
    dest_id = 0x02          # OCS
    msg_code = 0x01         # 상태보고
    ack_code = 0x00
    reserved = 0x0000
    data_length = 87        # 상태보고 데이터 크기
    
    header = struct.pack("<IBBBBHH",
        timestamp, source_id, dest_id, msg_code, ack_code,
        reserved, data_length
    )
    
    # 페이로드 (87바이트, 대부분 0으로 채움)
    payload = bytearray(87)
    payload[0] = 0b01000101  # 운용상태: 모드=010, 권한=01, 주행=01
    payload[6:8] = struct.pack("<H", 0b1111111111)  # 모든 장치 연결
    payload[20:22] = struct.pack("<H", 0b0000000000)  # 비상정지 없음
    
    # 체크섬 계산
    data = header + bytes(payload)
    checksum = sum(data) & 0xFFFF
    checksum_bytes = struct.pack("<H", checksum)
    
    return data + checksum_bytes

# 테스트 실행
parser = ICDParser()
packet = create_test_packet()

result = parser.parse(packet)

print(f"Success: {result.success}")
print(f"Checksum OK: {result.checksum_ok}")
if result.header:
    print(f"Sequence: {result.header.sequence}")
    print(f"MSG Code: 0x{result.header.msg_code:02X}")
if result.payload:
    print(f"Mode: {result.payload.operation_mode}")
    print(f"Authority: {result.payload.authority}")
    print(f"Driving: {result.payload.driving_state}")
    print(f"Devices: {result.payload.device_presence}")
