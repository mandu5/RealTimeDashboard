### 3. `ugv_mon/capture/stats.py`

> 패킷 캡처 통계를 추적하는 데이터 클래스입니다.

```python
"""
Capture Statistics Module.

패킷 캡처 중 발생하는 통계를 추적합니다:
- 총 패킷 수
- 필터 통과 패킷 수
- 바이트 수
- PPS (Packets Per Second)
"""

from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional


@dataclass
class CaptureStats:
    """
    패킷 캡처 통계 클래스.
    
    캡처 중 발생하는 각종 통계를 추적하고 계산합니다.
    스레드 간 공유될 수 있으므로 읽기 전용으로 사용하거나
    적절한 동기화가 필요합니다.
    
    Attributes:
        packets_total: 인터페이스에서 캡처된 총 패킷 수
        packets_filtered: BPF 필터를 통과한 패킷 수
        bytes_total: 캡처된 총 바이트 수
        start_time: 캡처 시작 시간
        last_packet_time: 마지막 패킷 수신 시간
    """
    
    # 패킷 카운터
    packets_total: int = 0
    packets_filtered: int = 0
    bytes_total: int = 0
    
    # 시간 정보
    start_time: Optional[datetime] = None
    last_packet_time: Optional[datetime] = None
    
    # PPS 계산용 (1초 윈도우)
    _pps_window_start: Optional[datetime] = field(default=None, repr=False)
    _pps_window_count: int = field(default=0, repr=False)
    _current_pps: int = field(default=0, repr=False)
    
    def record_packet(self, size: int, filtered: bool = True) -> None:
        """
        패킷 수신 기록.
        
        새 패킷이 수신될 때마다 호출하여 통계를 업데이트합니다.
        
        Args:
            size: 패킷 크기 (바이트)
            filtered: BPF 필터 통과 여부 (True면 통과)
        """
        now = datetime.now()
        
        # 총 패킷 수 증가
        self.packets_total += 1
        self.bytes_total += size
        
        # 필터 통과 시 filtered 카운트 증가
        if filtered:
            self.packets_filtered += 1
        
        # 시간 정보 업데이트
        if self.start_time is None:
            self.start_time = now
        self.last_packet_time = now
        
        # PPS 계산 (1초 윈도우)
        self._update_pps(now)
    
    def _update_pps(self, now: datetime) -> None:
        """
        PPS(초당 패킷 수) 업데이트.
        
        1초 윈도우를 사용하여 PPS를 계산합니다.
        윈도우가 지나면 카운터를 리셋합니다.
        
        Args:
            now: 현재 시간
        """
        # 첫 패킷이거나 1초가 지난 경우
        if self._pps_window_start is None:
            self._pps_window_start = now
            self._pps_window_count = 1
            return
        
        # 현재 윈도우 내의 시간 경과 계산
        elapsed = (now - self._pps_window_start).total_seconds()
        
        if elapsed >= 1.0:
            # 1초가 지났으면 PPS 확정 및 윈도우 리셋
            self._current_pps = self._pps_window_count
            self._pps_window_start = now
            self._pps_window_count = 1
        else:
            # 아직 1초 이내면 카운트만 증가
            self._pps_window_count += 1
    
    def get_pps(self) -> int:
        """
        현재 PPS(초당 패킷 수) 반환.
        
        마지막으로 완료된 1초 윈도우의 패킷 수를 반환합니다.
        
        Returns:
            초당 패킷 수 (정수)
        """
        return self._current_pps
    
    def get_filter_pass_pct(self) -> float:
        """
        필터 통과율 계산.
        
        전체 패킷 중 BPF 필터를 통과한 패킷의 비율을 계산합니다.
        
        Returns:
            필터 통과율 (0.0 ~ 100.0)
        """
        if self.packets_total == 0:
            return 100.0
        return (self.packets_filtered / self.packets_total) * 100.0
    
    def get_duration_sec(self) -> float:
        """
        캡처 지속 시간(초) 반환.
        
        Returns:
            캡처 시작부터 현재까지의 시간 (초)
        """
        if self.start_time is None:
            return 0.0
        return (datetime.now() - self.start_time).total_seconds()
    
    def reset(self) -> None:
        """
        통계 초기화.
        
        모든 통계 값을 초기 상태로 리셋합니다.
        캡처 재시작 시 호출합니다.
        """
        self.packets_total = 0
        self.packets_filtered = 0
        self.bytes_total = 0
        self.start_time = None
        self.last_packet_time = None
        self._pps_window_start = None
        self._pps_window_count = 0
        self._current_pps = 0
    
    def to_dict(self) -> dict:
        """
        딕셔너리로 변환.
        
        UI 표시용으로 통계를 딕셔너리로 변환합니다.
        
        Returns:
            통계 정보 딕셔너리
        """
        return {
            "packets_total": self.packets_total,
            "packets_filtered": self.packets_filtered,
            "bytes_total": self.bytes_total,
            "pps": self.get_pps(),
            "filter_pass_pct": round(self.get_filter_pass_pct(), 1),
            "duration_sec": round(self.get_duration_sec(), 1),
            "last_packet_time": (
                self.last_packet_time.strftime("%H:%M:%S") 
                if self.last_packet_time else ""
            ),
        }
```

**코드 설명 (줄별)**:

| 줄 | 설명 |
|---|------|
| `@dataclass` | Python 3.7+ 데이터 클래스 데코레이터. `__init__`, `__repr__` 자동 생성 |
| `field(default=0, repr=False)` | 기본값 설정 및 repr에서 제외 (내부용 필드) |
| `record_packet()` | 패킷 수신 시 호출. 통계 업데이트 |
| `_update_pps()` | 1초 슬라이딩 윈도우로 PPS 계산. `_` prefix는 내부 메서드 표시 |
| `elapsed = (now - self._pps_window_start).total_seconds()` | timedelta를 초 단위로 변환 |
| `get_filter_pass_pct()` | 0으로 나누기 방지 후 백분율 계산 |

### 4. `ugv_mon/capture/queue.py`

> 스레드 안전한 패킷 버퍼 큐입니다.

```python
"""
Thread-safe Packet Queue Module.

캡처 스레드(Producer)와 메인 스레드(Consumer) 간의
패킷 데이터를 안전하게 전달하는 버퍼입니다.

특징:
- collections.deque 기반 (O(1) 양방향 작업)
- maxlen으로 메모리 보호 (오래된 패킷 자동 드롭)
- threading.Lock으로 동기화
"""

import threading
from collections import deque
from typing import List, Optional
from datetime import datetime


class PacketQueue:
    """
    스레드 안전 패킷 큐.
    
    Producer-Consumer 패턴으로 패킷을 전달합니다:
    - Producer: PacketSniffer (캡처 스레드)
    - Consumer: UI 콜백 (메인 스레드)
    
    deque의 maxlen을 활용하여 메모리 사용량을 제한합니다.
    오버플로 시 가장 오래된 패킷이 자동으로 제거됩니다.
    
    Args:
        max_size: 최대 큐 크기 (기본값: 1000)
    
    Usage:
        queue = PacketQueue(max_size=500)
        
        # Producer (캡처 스레드)
        queue.put(packet_bytes)
        
        # Consumer (메인 스레드)
        packets = queue.get_all()  # 모든 패킷 가져오기
    """
    
    def __init__(self, max_size: int = 1000):
        """
        패킷 큐 초기화.
        
        Args:
            max_size: 최대 저장 가능한 패킷 수
                      초과 시 가장 오래된 패킷이 제거됨
        """
        # deque: 양방향 큐. maxlen 설정 시 자동으로 오래된 항목 제거
        self._queue: deque = deque(maxlen=max_size)
        
        # threading.Lock: 스레드 간 동기화용 뮤텍스
        # with문과 함께 사용하여 안전한 접근 보장
        self._lock = threading.Lock()
        
        # 통계용 타임스탬프
        self._last_put_time: Optional[datetime] = None
    
    def put(self, packet: bytes) -> None:
        """
        패킷을 큐에 추가.
        
        캡처 스레드에서 호출됩니다.
        큐가 가득 차면 가장 오래된 패킷이 자동으로 제거됩니다.
        
        Args:
            packet: 원시 패킷 바이트 데이터
        """
        # with문: lock.acquire() 후 블록 종료 시 lock.release() 자동 호출
        with self._lock:
            self._queue.append(packet)
            self._last_put_time = datetime.now()
    
    def get(self) -> Optional[bytes]:
        """
        큐에서 가장 오래된 패킷 하나를 꺼냄.
        
        FIFO(First-In-First-Out) 순서로 패킷을 반환합니다.
        큐가 비어있으면 None을 반환합니다.
        
        Returns:
            패킷 바이트 데이터 또는 None
        """
        with self._lock:
            if len(self._queue) == 0:
                return None
            # popleft(): 왼쪽(가장 오래된)에서 제거하며 반환
            return self._queue.popleft()
    
    def get_all(self) -> List[bytes]:
        """
        큐의 모든 패킷을 한 번에 꺼냄.
        
        UI 갱신 시 사용합니다.
        호출 후 큐는 비워집니다.
        
        Returns:
            패킷 리스트 (비어있으면 빈 리스트)
        """
        with self._lock:
            # list()로 복사 후 clear()로 원본 비우기
            packets = list(self._queue)
            self._queue.clear()
            return packets
    
    def peek(self) -> Optional[bytes]:
        """
        큐의 맨 앞 패킷을 제거하지 않고 확인.
        
        Returns:
            맨 앞 패킷 또는 None
        """
        with self._lock:
            if len(self._queue) == 0:
                return None
            return self._queue[0]
    
    def size(self) -> int:
        """
        현재 큐에 저장된 패킷 수.
        
        Returns:
            패킷 수 (정수)
        """
        with self._lock:
            return len(self._queue)
    
    def is_empty(self) -> bool:
        """
        큐가 비어있는지 확인.
        
        Returns:
            비어있으면 True
        """
        return self.size() == 0
    
    def clear(self) -> None:
        """
        큐의 모든 패킷 제거.
        
        큐를 초기화해야 할 때 호출합니다.
        """
        with self._lock:
            self._queue.clear()
    
    @property
    def last_put_time(self) -> Optional[datetime]:
        """
        마지막 패킷 추가 시간.
        
        Returns:
            마지막 put() 호출 시간 또는 None
        """
        return self._last_put_time
```

**코드 설명 (핵심 개념)**:

| 개념 | 설명 |
|------|------|
| `deque(maxlen=N)` | 크기가 N을 초과하면 반대쪽에서 자동 제거. 메모리 보호 |
| `threading.Lock()` | 뮤텍스. 한 번에 하나의 스레드만 접근 허용 |
| `with self._lock:` | Context Manager. acquire/release 자동 처리 |
| `popleft()` | O(1) 시간복잡도로 왼쪽에서 제거. list.pop(0)은 O(n) |
| `Optional[T]` | T 또는 None 반환 가능함을 명시 |

**Q&A**:

**Q: 왜 deque를 사용하나요?**
A: `list`와 달리 `deque`는 양쪽 끝에서의 삽입(append)과 삭제(pop)가 O(1) 시간 복잡도로 매우 효율적입니다.
   이는 실시간으로 패킷이 들어오고 처리되는 환경에 적합합니다.
   또한 `maxlen`을 설정하여 큐 크기를 자동으로 관리할 수 있습니다.

**Q: 왜 스레드 안전이 필요한가요?**
A: PacketSniffer 스레드(Producer)와 메인 UI 스레드(Consumer)가 동시에 큐에 접근할 수 있으므로,
   데이터 일관성을 위해 락(Lock)을 사용합니다.
   `with self._lock:` 구문으로 안전하게 접근합니다.

**Q: maxlen을 설정하면 어떻게 되나요?**
A: 큐 크기가 maxlen을 초과하면 가장 오래된(왼쪽) 패킷이 자동으로 제거됩니다.
   따라서 큐 크기를 수동으로 관리할 필요가 없습니다.

### 5. `ugv_mon/capture/sniffer.py`

> Scapy 기반 패킷 스니퍼. **핵심 모듈**입니다.

```python
"""
Scapy-based Packet Sniffer Module.

VIC→OCS UDP 패킷을 실시간으로 캡처합니다.

특징:
- BPF(Berkeley Packet Filter) 커널 레벨 필터링
- 별도 데몬 스레드에서 캡처 (UI 블로킹 방지)
- 콜백 기반 패킷 전달

요구사항:
- root 권한 필요 (sudo python run.py)
- scapy 패키지 설치 필요

사용 예시:
    def handle_packet(raw_bytes):
        print(f"Received {len(raw_bytes)} bytes")
    
    sniffer = PacketSniffer(
        interface="lo",
        src_port=50000,
        dst_port=61000,
        callback=handle_packet
    )
    sniffer.start()
    # ... 작업 수행 ...
    sniffer.stop()
"""

import threading
import logging
from typing import Callable, Optional
from datetime import datetime

# Scapy import (패킷 캡처 라이브러리)
# 경고 메시지 억제
import warnings
warnings.filterwarnings("ignore", category=DeprecationWarning)

try:
    from scapy.all import sniff, UDP, Raw
    from scapy.packet import Packet
    SCAPY_AVAILABLE = True
except ImportError:
    SCAPY_AVAILABLE = False
    Packet = None  # 타입 힌트용

from .stats import CaptureStats

# 로거 설정
logger = logging.getLogger(__name__)


class PacketSniffer:
    """
    UDP 패킷 스니퍼 클래스.
    
    Scapy를 사용하여 지정된 인터페이스에서 UDP 패킷을 캡처합니다.
    BPF 필터를 사용하여 특정 포트의 패킷만 선택적으로 캡처합니다.
    
    Attributes:
        interface: 캡처할 네트워크 인터페이스 (예: "lo", "eno2")
        src_port: 송신 포트 (VIC 측)
        dst_port: 수신 포트 (OCS 측)
        callback: 패킷 수신 시 호출할 콜백 함수
    
    Warning:
        - root 권한이 필요합니다 (sudo)
        - 콜백 함수는 빠르게 실행되어야 합니다 (캡처 스레드 블로킹 방지)
    """
    
    def __init__(
        self,
        interface: str,
        src_port: int,
        dst_port: int,
        callback: Callable[[bytes], None]
    ):
        """
        PacketSniffer 초기화.
        
        Args:
            interface: 네트워크 인터페이스명
                       - "lo": 루프백 (개발/테스트용)
                       - "eno2", "eno3": 물리 인터페이스 (프로덕션)
            src_port: 송신측 UDP 포트 (VIC: 50000)
            dst_port: 수신측 UDP 포트 (OCS: 61000)
            callback: 패킷 수신 시 호출할 함수
                      signature: (raw_bytes: bytes) -> None
        
        Raises:
            ImportError: Scapy가 설치되지 않은 경우
        """
        if not SCAPY_AVAILABLE:
            raise ImportError(
                "Scapy is not installed. Run: pip install scapy"
            )
        
        self._interface = interface
        self._src_port = src_port
        self._dst_port = dst_port
        self._callback = callback
        
        # BPF 필터 문자열 생성
        # "udp and src port 50000 and dst port 61000"
        self._filter = f"udp and src port {src_port} and dst port {dst_port}"
        
        # 스레드 제어용 플래그
        self._running = False
        self._thread: Optional[threading.Thread] = None
        
        # 통계
        self._stats = CaptureStats()
        
        logger.info(
            f"PacketSniffer initialized: {interface}, "
            f"filter='{self._filter}'"
        )
    
    def start(self) -> None:
        """
        패킷 캡처 시작.
        
        별도의 데몬 스레드에서 캡처 루프를 시작합니다.
        이미 실행 중이면 아무 동작도 하지 않습니다.
        
        Note:
            - 데몬 스레드: 메인 프로세스 종료 시 자동 종료
            - start() 호출 후 즉시 반환 (비동기)
        """
        if self._running:
            logger.warning("Sniffer is already running")
            return
        
        self._running = True
        self._stats.reset()
        
        # 데몬 스레드 생성 및 시작
        # daemon=True: 메인 스레드 종료 시 같이 종료
        self._thread = threading.Thread(
            target=self._capture_loop,
            name="PacketSniffer",
            daemon=True
        )
        self._thread.start()
        
        logger.info(f"Sniffer started on interface '{self._interface}'")
    
    def stop(self) -> None:
        """
        패킷 캡처 중지.
        
        캡처 루프를 종료하고 스레드가 끝날 때까지 대기합니다.
        최대 2초 대기 후 타임아웃됩니다.
        """
        if not self._running:
            logger.warning("Sniffer is not running")
            return
        
        self._running = False
        
        # 스레드 종료 대기 (최대 2초)
        if self._thread and self._thread.is_alive():
            self._thread.join(timeout=2.0)
            if self._thread.is_alive():
                logger.warning("Sniffer thread did not terminate in time")
        
        logger.info("Sniffer stopped")
    
    def is_running(self) -> bool:
        """
        스니퍼 실행 상태 확인.
        
        Returns:
            실행 중이면 True
        """
        return self._running
    
    def get_stats(self) -> CaptureStats:
        """
        캡처 통계 반환.
        
        Returns:
            CaptureStats 인스턴스
        """
        return self._stats
    
    def _capture_loop(self) -> None:
        """
        패킷 캡처 루프 (스레드에서 실행).
        
        Scapy의 sniff() 함수를 사용하여 패킷을 캡처합니다.
        stop_filter 콜백으로 _running 플래그를 확인하여 종료합니다.
        
        Note:
            이 메서드는 직접 호출하지 않습니다.
            start()에서 스레드로 실행됩니다.
        """
        logger.info(f"Capture loop started, filter: {self._filter}")
        
        try:
            # Scapy sniff() 함수 호출
            # prn: 각 패킷마다 호출되는 콜백
            # filter: BPF 필터 문자열
            # iface: 네트워크 인터페이스
            # store: False면 메모리에 패킷 저장 안 함 (성능)
            # stop_filter: True 반환 시 캡처 중지
            sniff(
                prn=self._process_packet,
                filter=self._filter,
                iface=self._interface,
                store=False,
                stop_filter=lambda _: not self._running
            )
        except PermissionError:
            logger.error(
                "Permission denied. Run with sudo: sudo python run.py"
            )
            self._running = False
        except OSError as e:
            logger.error(f"OS error during capture: {e}")
            self._running = False
        except Exception as e:
            logger.error(f"Unexpected error in capture loop: {e}")
            self._running = False
        finally:
            logger.info("Capture loop ended")
    
    def _process_packet(self, packet: Packet) -> None:
        """
        개별 패킷 처리.
        
        Scapy의 sniff()에서 패킷이 수신될 때마다 호출됩니다.
        UDP 페이로드를 추출하여 콜백 함수에 전달합니다.
        
        Args:
            packet: Scapy 패킷 객체
        
        Note:
            - 이 함수는 캡처 스레드에서 실행됩니다
            - 빠르게 처리해야 패킷 드롭이 발생하지 않습니다
        """
        try:
            # UDP 레이어와 Raw(페이로드) 레이어 확인
            if UDP in packet and Raw in packet:
                # Raw 레이어에서 바이트 데이터 추출
                raw_data = bytes(packet[Raw].load)
                
                # 통계 업데이트
                self._stats.record_packet(len(raw_data), filtered=True)
                
                # 콜백 함수 호출 (보통 PacketQueue.put)
                self._callback(raw_data)
                
        except Exception as e:
            # 패킷 처리 실패해도 캡처는 계속
            logger.debug(f"Error processing packet: {e}")
    
    @property
    def interface(self) -> str:
        """캡처 인터페이스명."""
        return self._interface
    
    @property
    def filter_str(self) -> str:
        """BPF 필터 문자열."""
        return self._filter
```

**코드 설명 (핵심 개념)**:

| 줄/섹션 | 설명 |
|---------|------|
| `from scapy.all import sniff, UDP, Raw` | Scapy 핵심 함수/클래스 import |
| `SCAPY_AVAILABLE` | 선택적 의존성 처리. Scapy 없으면 ImportError |
| `self._filter = f"udp and src port..."` | BPF 필터 문자열. 커널에서 필터링 |
| `daemon=True` | 데몬 스레드. 메인 종료 시 자동 종료 |
| `sniff(..., store=False, ...)` | 메모리에 패킷 저장 안 함. 성능 최적화 |
| `stop_filter=lambda _: not self._running` | 캡처 루프 종료 조건. _running이 False면 종료 |
| `packet[Raw].load` | 패킷의 Raw(페이로드) 레이어에서 바이트 추출 |

**Q&A**:

**Q: 왜 Scapy를 사용하나요?**
A: Scapy는 강력한 패킷 조작 및 분석 라이브러리로, 낮은 레벨의 네트워크 패킷을
   쉽게 캡처하고 필터링할 수 있습니다. 프로토콜 스택을 이해하고 디코딩하는 데 유용합니다.

**Q: 왜 별도의 스레드에서 실행하나요?**
A: 패킷 캡처는 지속적으로 네트워크를 모니터링해야 하는 작업입니다.
   이를 메인 UI 스레드에서 실행하면 UI가 멈추거나 응답하지 않게 됩니다.
   별도의 스레드에서 실행하여 UI의 반응성을 유지합니다.

**Q: BPF 필터는 무엇인가요?**
A: Berkeley Packet Filter의 약자로, 네트워크 인터페이스에서 특정 조건에 맞는
   패킷만 선택적으로 캡처하기 위한 규칙입니다. 예를 들어, 특정 IP 주소나 포트 번호로
   들어오고 나가는 패킷만 필터링할 수 있습니다. 커널 레벨에서 필터링하므로 효율적입니다.

**Q: 왜 `store=False`를 사용하나요?**
A: Scapy의 기본 동작은 모든 패킷을 메모리에 저장하는데, 이는 메모리 부족을 야기할 수 있습니다.
   `store=False`로 설정하면 패킷을 저장하지 않고 콜백만 호출하여 메모리 사용량을 최소화합니다.

**Q: `daemon=True`는 무엇인가요?**
A: 데몬 스레드는 메인 프로세스가 종료될 때 자동으로 종료되는 스레드입니다.
   이를 사용하면 메인 프로그램 종료 시 캡처 스레드도 자동으로 정리됩니다.
