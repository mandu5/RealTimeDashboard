### 1. `ugv_mon/capture/sniffer.py` - 패킷 스니퍼

**역할**: Scapy를 사용하여 네트워크 인터페이스에서 UDP 패킷을 실시간 캡처하고 필터링

**구현 내용**:

```python
"""
Scapy 기반 패킷 캡처 모듈

역할:
- 지정된 인터페이스(lo/eno2)에서 UDP 패킷 캡처
- BPF 필터 적용 (srcport=50000, dstport=61000)
- 패킷 큐에 저장하여 처리 모듈에 전달
- 캡처 통계 추적
"""

from scapy.all import sniff, UDP, IP
from queue import Queue
from threading import Thread
from typing import Optional
import time

from ..config import config


class PacketSniffer:
    """
    실시간 패킷 캡처 클래스
    
    Scapy를 사용하여 네트워크 인터페이스에서 UDP 패킷을 캡처합니다.
    BPF 필터를 통해 VIC→OCS 트래픽(50000→61000)만 수집합니다.
    
    사용법:
        sniffer = PacketSniffer(interface="lo")
        sniffer.start()
        packet = sniffer.get_packet(timeout=1.0)
        stats = sniffer.get_stats()
        sniffer.stop()
    """
    
    def __init__(self, interface: str = None):
        """
        초기화
        
        Args:
            interface: 캡처할 네트워크 인터페이스 (기본값: config에서 가져옴)
        """
        self.interface = interface or config.network.interface
        self.running = False
        self._thread: Optional[Thread] = None
        self.packet_queue = Queue(maxsize=1000)  # 최대 1000개 패킷 버퍼
        
        # 통계
        self.total_captured = 0  # 총 캡처된 패킷 수 (필터 전)
        self.total_filtered = 0  # 필터를 통과한 패킷 수
        
        # 성능 측정
        self._start_time: Optional[float] = None
        
    def _get_bpf_filter(self) -> str:
        """
        BPF 필터 문자열 반환
        
        VIC→OCS 트래픽만 캡처:
        - Source port: 50000
        - Destination port: 61000
        - Protocol: UDP
        
        Returns:
            BPF 필터 문자열
        """
        src_port = config.network.source_port
        dst_port = config.network.dest_port
        return f"udp src port {src_port} and udp dst port {dst_port}"
    
    def _packet_callback(self, packet):
        """
        패킷 수신 콜백
        
        Scapy sniff() 함수가 호출하는 콜백입니다.
        UDP 패킷인 경우 큐에 추가하고 통계를 업데이트합니다.
        
        Args:
            packet: Scapy 패킷 객체
        """
        self.total_captured += 1
        
        # UDP 패킷 확인
        if UDP in packet:
            self.total_filtered += 1
            
            # 큐가 가득 차면 오래된 패킷 버림 (FIFO)
            if self.packet_queue.full():
                try:
                    self.packet_queue.get_nowait()
                except:
                    pass
            
            # 새 패킷 추가
            self.packet_queue.put(packet)
    
    def start(self):
        """
        캡처 시작
        
        별도 스레드에서 스니핑을 시작합니다.
        메인 스레드를 블로킹하지 않기 위해 비동기 실행됩니다.
        """
        if self.running:
            return
        
        self.running = True
        self._start_time = time.time()
        self._thread = Thread(target=self._sniff_loop, daemon=True)
        self._thread.start()
    
    def _sniff_loop(self):
        """
        스니핑 루프
        
        Scapy sniff() 함수를 호출하여 패킷을 캡처합니다.
        self.running이 False가 될 때까지 실행됩니다.
        """
        try:
            sniff(
                iface=self.interface,
                filter=self._get_bpf_filter(),
                prn=self._packet_callback,
                store=False,  # 메모리 절약을 위해 패킷 저장 안 함
                stop_filter=lambda _: not self.running,
            )
        except Exception as e:
            print(f"Sniffing error: {e}")
            self.running = False
    
    def stop(self):
        """
        캡처 중지
        
        스니핑 루프를 종료하고 스레드를 정리합니다.
        """
        self.running = False
        if self._thread:
            self._thread.join(timeout=2.0)
    
    def get_packet(self, timeout: float = 0.1):
        """
        큐에서 패킷 가져오기
        
        Args:
            timeout: 대기 시간 (초)
            
        Returns:
            Scapy 패킷 객체 또는 None (타임아웃 시)
        """
        try:
            return self.packet_queue.get(timeout=timeout)
        except:
            return None
    
    def get_stats(self) -> dict:
        """
        캡처 통계 반환
        
        Returns:
            통계 딕셔너리:
            - total_captured: 총 캡처된 패킷 수
            - total_filtered: 필터 통과 패킷 수
            - queue_size: 현재 큐 크기
            - capture_pps: 초당 캡처 패킷 수 (근사치)
        """
        elapsed = time.time() - self._start_time if self._start_time else 1.0
        pps = self.total_filtered / elapsed if elapsed > 0 else 0
        
        return {
            "total_captured": self.total_captured,
            "total_filtered": self.total_filtered,
            "queue_size": self.packet_queue.qsize(),
            "capture_pps": int(pps),
        }
    
    def clear_queue(self):
        """큐 비우기"""
        while not self.packet_queue.empty():
            try:
                self.packet_queue.get_nowait()
            except:
                break
```

**설명 및 근거**:
- **Scapy 사용**: raw socket보다 높은 추상화, BPF 필터 내장 지원
- **별도 스레드**: 메인 스레드 블로킹 방지
- **Queue 사용**: 스레드 안전한 패킷 전달
- **store=False**: 메모리 절약 (패킷 저장 안 함)
- **큐 크기 제한**: 메모리 폭주 방지

### 2. `ugv_mon/capture/filter.py` - BPF 필터 유틸리티 (선택적)

**역할**: BPF 필터 생성 및 검증 유틸리티

**구현 내용**:

```python
"""
BPF 필터 유틸리티

VIC→OCS 트래픽 필터링을 위한 BPF 필터 생성 및 검증
"""

from ..config import config


def get_vic_ocs_filter() -> str:
    """
    VIC→OCS 트래픽 BPF 필터 반환
    
    Returns:
        BPF 필터 문자열
    """
    src_port = config.network.source_port
    dst_port = config.network.dest_port
    return f"udp src port {src_port} and udp dst port {dst_port}"


def validate_filter(filter_str: str) -> bool:
    """
    BPF 필터 문자열 검증
    
    Args:
        filter_str: BPF 필터 문자열
        
    Returns:
        유효하면 True, 아니면 False
    """
    # 간단한 검증 (실제로는 Scapy에서 파싱 시도)
    required_keywords = ["udp", "port"]
    return all(keyword in filter_str.lower() for keyword in required_keywords)
```

**설명 및 근거**:
- **유틸리티 함수**: 재사용 가능한 필터 생성
- **검증 함수**: 잘못된 필터 방지

from ugv_mon.capture.sniffer import PacketSniffer
import time

sniffer = PacketSniffer(interface="lo")

sniffer.start()

print(f"Filtered: {stats['total_filtered']}")
