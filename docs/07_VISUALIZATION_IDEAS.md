## 3. 시각화 개선 아이디어

### 3.1 게이지 차트 (Gauge)

**적용 대상**: 가용성, PPS

```python
go.Indicator(
    mode="gauge+number",
    value=99.8,
    title={"text": "가용성 (%)"},
    gauge={"axis": {"range": [0, 100]}}
)
```
