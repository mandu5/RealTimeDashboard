## 1. 현재 문제점

### 1.1 단조로운 그래프

| 지표 | 현재 값 | 증상 |
|------|---------|------|
| PPS | 고정 ~6 | poll interval 2초 × 3 pps = 6으로 고정 |
| 지터 | 고정 ~0ms | 데이터 흔들림이 거의 없음 |
| 차트 | 직선 | 변동 없어 시각적 흥미 부족 |

### 1.2 원인 분석

```
[캡처] 3 pps → [큐] → [2초 폴링] → 한번에 6개 처리
                              └→ PPS = 6 고정
                              └→ 지터 = 0ms (안정적인 통신)
```

## 2. 시뮬레이터 테스트 계획

### 2.1 테스트 항목

| 테스트 | 방법 | 목적 |
|--------|------|------|
| 지터 변동 | 패킷 전송 간격 변조 (±50ms) | 지터 그래프 변동 확인 |
| 패킷 손실 | 시퀀스 임의 skip | 손실 감지 확인 |
| 연결 끊김 | 전송 일시 중지 (5초+) | 가용성 하락, 알림 발생 확인 |
| PPS 변동 | 전송 빈도 변경 (1→5→1 pps) | PPS 그래프 변동 확인 |

### 2.2 테스트 순서

1. VCS_Simulator 코드 분석
2. 패킷 전송 간격 변조 코드 추가
3. 대시보드 연결 후 그래프 확인
4. 필요 시 차트 개선 결정

## 3. 시각화 개선 아이디어

### 3.1 게이지 차트 (Gauge)

**적용 대상**: 가용성, PPS

```
┌────────────────┐
│   가용성 99.8% │
│  ╭───────────╮ │
│  │ ▓▓▓▓▓▓▓░░ │ │
│  ╰───────────╯ │
└────────────────┘
```

**장점**: 현재 값을 직관적으로 표시
**구현**: `go.Indicator(mode="gauge+number")`

### 3.2 스파크라인 (Sparkline)

**적용 대상**: KPI 카드 내 미니 차트

```
┌─────────────────────┐
│ PPS              6  │
│ ─╱╲─╱╲─╱╲─╱╲─      │
└─────────────────────┘
```

**장점**: 공간 효율적, 추세 한눈에 확인
**구현**: `dcc.Graph`에 작은 라인 차트

### 3.3 히트맵 타임라인

**적용 대상**: 가용성, 지터

```
│ 12:00 │ 12:01 │ 12:02 │ 12:03 │
│ ███████ ███████ ░░░░░░░ ███████ │
│ 100%   100%   85%    100%  │
```

**장점**: 시간별 상태 변화 한눈에 파악
**구현**: `go.Heatmap`

### 3.4 애니메이션 효과

**적용 대상**: 연결 상태 LED, PPS 카운터

- LED 깜빡임 (패킷 수신 시)
- 숫자 카운트업 애니메이션
- 상태 변경 시 하이라이트

**구현**: CSS Keyframes + Dash Interval

### 3.5 다중 Y축 차트

**적용 대상**: PPS + 지터 통합 차트

```
PPS (좌)    │                  │ 지터 (우)
    8 ─     │    ╱╲    ╱╲      │ ─ 10ms
    6 ─     │ ──┴──┴────       │ ─ 5ms
    4 ─     │                  │ ─ 0ms
```

**장점**: 두 지표 상관관계 파악
**구현**: `make_subplots(..., specs=[[{"secondary_y": True}]])`

## 4. 데이터 변동이 없는 경우 대안

### 4.1 Mock 모드 개선

```python
# mock_data.py에서 변동 추가
import random

pps = 1024 + random.randint(-50, 50)  # ±50 변동
jitter = 2.0 + random.uniform(-0.5, 0.5)  # ±0.5ms 변동
```

### 4.2 시뮬레이션 데이터 오버레이

- 실제 데이터 위에 시뮬레이션 예시 표시
- "데모 모드" 토글로 활성화

### 4.3 통계 요약 강조

- 변동이 없어도 의미 있는 정보:
  - 총 수신 패킷 수 (누적)
  - 가동 시간 (uptime)
  - 세션 시작 이후 평균 지터

## 5. 결정 대기

> 내일 VCS_Simulator 테스트 후 결정:

1. **지터 변동이 있으면**: P95/P99 오버레이 차트 개선
2. **지터 변동이 없으면**: 게이지 차트로 전환 또는 스파크라인 추가
3. **PPS 변동이 있으면**: 현재 라인 차트 유지
4. **PPS 변동이 없으면**: 숫자 카운터 + 작은 히스토리 표시
