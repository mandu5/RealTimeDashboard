# UGV-MON 프로젝트 개요

> **최종 업데이트**: 2026-02-08

## 프로젝트 소개

**UGV-MON**은 무인지상차량(UGV)의 VIC(차량연동통제기)↔OCS(운용통제기) 간 UDP 통신을 **수동 감시**하는 실시간 대시보드입니다.

### 핵심 기능

1. **ICD v1.0 규격 파싱** - 메시지 해석 및 검증
2. **실시간 KPI 분석** - PPS, 지터, 가용성, 패킷 손실
3. **운용 상태 모니터링** - 모드, 권한, 주행상태, 장치 연결
4. **ML 이상 탐지** - Isolation Forest 기반 자동 감지

## 핵심 제약사항

| 항목           | 내용                                |
| -------------- | ----------------------------------- |
| **수동 감시**  | 제어 패킷 송신 불가 (모니터링 전용) |
| **환경**       | 내부망 Linux, 인터넷 연결 불가      |
| **Python**     | 3.10+                               |
| **프레임워크** | Dash + Plotly + DMC + AG-Grid       |
| **갱신 방식**  | Polling (dcc.Interval, 2초)         |

## 기술 스택

| 계층   | 기술                | 목적                            |
| ------ | ------------------- | ------------------------------- |
| 캡처   | Scapy               | 패킷 스니핑 및 BPF 필터링       |
| 파싱   | struct              | ICD 헤더/페이로드 파싱          |
| 저장   | PacketStore (deque) | 단일 저장소 기반 통계/이력      |
| 분석   | scikit-learn        | ML 이상 탐지 (Isolation Forest) |
| UI     | Dash + Mantine      | 대시보드 프레임워크             |
| 차트   | Plotly              | 시계열 시각화                   |
| 테이블 | AG-Grid             | 고성능 로그 테이블              |

## 실행 모드

### Mock 모드 (개발/테스트)

```bash
python3 run.py
python3 run.py --mode mock
```

### Live 모드 (실제 캡처)

```bash
sudo python3 run.py --mode live --interface lo
sudo python3 run.py --mode live --interface eno2
```

## 주요 KPI (8개)

| KPI           | 설명                | 소스                             |
| ------------- | ------------------- | -------------------------------- |
| 수신 PPS      | 초당 패킷 수        | `PacketStore.get_pps()`          |
| 필터 통과율   | BPF 필터 통과 비율  | 캡처 통계                        |
| 파싱 성공률   | ICD 파싱 성공 비율  | `PacketStore` 집계               |
| 체크섬 오류율 | 무결성 검증 실패    | `PacketStore` 집계               |
| 패킷 손실     | 시퀀스 갭 기반 추정 | `PacketStore.get_packet_loss()`  |
| 가용성 (5분)  | 연결 시간 비율      | `PacketStore.get_availability()` |
| 지터 (현재)   | 현재 패킷 간격 변동 | `PacketStore` 계산               |
| 지터 (P95)    | 95번째 백분위 지터  | `PacketStore.get_jitter_p95()`   |

| ------------------- | --------------------------- |
