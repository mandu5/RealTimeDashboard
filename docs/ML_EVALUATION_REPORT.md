# ML 이상 탐지 평가 보고서

## 개요

UGV-MON 대시보드에 구현된 앙상블 이상 탐지 시스템의 성능 평가 및 설계 결정 문서입니다.

---

## 시스템 아키텍처

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│   PacketStore   │────▶│   Rule Detector  │────▶│                 │
│   (실시간 KPI)   │     │   (임계값 기반)    │     │   앙상블 판정    │
└─────────────────┘     └──────────────────┘     │   (OR 로직)     │
        │                                         │                 │
        │               ┌──────────────────┐     │                 │
        └──────────────▶│   ML Pipeline    │────▶│                 │
                        │ (Isolation Forest) │     └─────────────────┘
                        └──────────────────┘
```

---

## 탐지 방식 비교

| 항목            | Rule-Based   | ML (Isolation Forest) |
| --------------- | ------------ | --------------------- |
| **학습 필요**   | ❌ 없음      | ✅ 500 샘플 필요      |
| **Cold Start**  | ✅ 즉시 작동 | ❌ 학습 대기          |
| **해석 가능성** | ✅ 명확      | ⚠️ 제한적             |
| **복잡한 패턴** | ❌ 불가      | ✅ 가능               |

## 장점 및 한계

### 장점

1. **Cold Start 해결**: Rule이 즉시 작동
2. **False Negative 최소화**: OR 로직으로 놓치는 이상 감소
3. **해석 가능성**: Rule 위반 시 명확한 이유 제공

### 한계

1. **False Positive 증가 가능**: OR 로직으로 오탐 증가 가능
2. **Rule 임계값 튜닝 필요**: 환경에 따라 조정 필요

---

## 향후 개선 방향

1. **롤링 재학습**: 1시간마다 최근 데이터로 재학습
2. **시간대별 모델**: 주간/야간 별도 모델
3. **임계값 자동 튜닝**: 히스토리 기반 동적 임계값
