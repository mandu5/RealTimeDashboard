### 1. `ugv_mon/config.py` - 설정 관리

**역할**: 모든 설정을 중앙에서 관리하는 dataclass 기반 설정 시스템

**구현 내용**:

```python
"""
UGV-MON Dashboard Configuration Module.

Centralizes all configuration settings for the monitoring dashboard.
Settings can be overridden via environment variables for deployment flexibility.
"""

import os
from dataclasses import dataclass, field
from typing import Dict, List


@dataclass
class AppConfig:
    """Application server configuration."""
    name: str = "UGV-MON Dashboard"
    version: str = "1.0.0"
    debug: bool = True
    host: str = "0.0.0.0"
    port: int = 8050


@dataclass
class NetworkConfig:
    """Network capture configuration for VIC↔OCS monitoring."""
    interface: str = "lo"  # lo for loopback, eno2/eno3 for production
    source_port: int = 50000  # VIC→OCS flow
    dest_port: int = 61000
    buffer_size: int = 4096


@dataclass
class UIConfig:
    """Dashboard UI configuration."""
    poll_interval_ms: int = 2000  # 2 seconds
    max_log_entries: int = 200
    max_chart_points: int = 60
    timeline_duration_sec: int = 3600  # 1 hour
    availability_window_5min: int = 300
    availability_window_1hour: int = 3600
    down_threshold_sec: float = 5.0


@dataclass
class Config:
    """Master configuration container."""
    app: AppConfig = field(default_factory=AppConfig)
    network: NetworkConfig = field(default_factory=NetworkConfig)
    ui: UIConfig = field(default_factory=UIConfig)
    
    @classmethod
    def from_env(cls) -> "Config":
        """Create configuration from environment variables."""
        config = cls()
        if os.getenv("UGV_MON_PORT"):
            config.app.port = int(os.getenv("UGV_MON_PORT"))
        if os.getenv("UGV_MON_INTERFACE"):
            config.network.interface = os.getenv("UGV_MON_INTERFACE")
        if os.getenv("UGV_MON_POLL_INTERVAL"):
            config.ui.poll_interval_ms = int(os.getenv("UGV_MON_POLL_INTERVAL"))
        return config


# Global configuration instance
config = Config.from_env()
```

**설명 및 근거**:
- **Dataclass 사용**: 타입 안전성과 가독성 향상
- **환경변수 지원**: 배포 환경별 설정 유연성
- **섹션 분리**: App/Network/UI로 논리적 그룹화

### 2. `ugv_mon/data/models.py` - 데이터 모델

**역할**: 대시보드에서 사용하는 모든 데이터 구조를 타입으로 정의

**구현 내용**:

```python
"""
Data models for UGV-MON Dashboard.

Defines structured data types for:
- Dashboard state (KPIs, operational status)
- Log entries (packet records)
- Device status (connectivity grid)
"""

from dataclasses import dataclass, field
from datetime import datetime
from typing import Dict, List, Optional
from enum import Enum


class OperationMode(Enum):
    """VIC operation mode (bits 7..5 of state byte)."""
    PREP = 0b000
    TRANSITION = 0b001
    UNMANNED_DRIVING = 0b010
    UNMANNED_FIRING = 0b011
    EMERGENCY_STOP = 0b100
    UNKNOWN = 0xFF


class Authority(Enum):
    """VIC authority state (bits 3..2 of state byte)."""
    RELEASED = 0b00
    OCS_ACQUIRED = 0b01
    NEAR_CONTROLLER = 0b10
    UNKNOWN = 0xFF


class DrivingState(Enum):
    """VIC driving state (bits 1..0 of state byte)."""
    REMOTE = 0b01
    PLATOON = 0b10
    AUTONOMOUS_DISPATCH = 0b11
    UNKNOWN = 0xFF


@dataclass
class DashboardState:
    """Complete dashboard state for UI rendering."""
    # Connection info
    connected: bool = True
    interface: str = "lo"
    filter_desc: str = "50000→61000"
    last_packet_time: str = ""
    
    # KPI metrics
    capture_pps: int = 0
    filter_pass_pct: float = 100.0
    parse_success_pct: float = 100.0
    checksum_fail_pct: float = 0.0
    packet_loss_count: int = 0
    availability_5min: float = 100.0
    availability_1hour: float = 100.0
    jitter_p95_ms: float = 0.0
    jitter_p99_ms: float = 0.0
    
    # Operational state
    operation_mode: str = "준비 (PREP)"
    authority: str = "해제됨 (RELEASED)"
    driving_state: str = "원격 (REMOTE)"
    
    # Collections
    devices: List[Dict] = field(default_factory=list)
    emergency_status: Dict[str, bool] = field(default_factory=dict)
    chart_data: List[Dict] = field(default_factory=list)
    availability_segments: List[Dict] = field(default_factory=list)
    
    def to_dict(self) -> Dict:
        """Convert to dictionary for dcc.Store."""
        return {
            "connected": self.connected,
            "interface": self.interface,
            "filter": self.filter_desc,
            "lastPacketTime": self.last_packet_time,
            "capturePps": self.capture_pps,
            # ... (나머지 필드)
        }
```

**코드 설명 (핵심 개념)**:

| 개념 | 설명 |
|------|------|
| `@dataclass` | Python 3.7+ 데이터 클래스 데코레이터. `__init__`, `__repr__`, `__eq__` 자동 생성 |
| `field(default_factory=list)` | 리스트 필드의 기본값. 매 인스턴스마다 새 리스트 생성 (공유 방지) |
| `Enum` | 상수 값 집합 정의. ICD 규격의 비트 값과 매핑 명확화 |
| `to_dict()` | JSON 직렬화를 위한 변환. Dash의 `dcc.Store`에 저장하기 위해 딕셔너리로 변환 |

**Q&A**:

**Q: 왜 Enum을 사용하나요?**
A: ICD 규격의 비트 값(예: 운용 모드 0b000, 0b001)을 명확하게 매핑하기 위함입니다.
   숫자 대신 `OperationMode.PREP`처럼 의미 있는 이름을 사용하여 코드 가독성을 높입니다.

**Q: 왜 dataclass를 사용하나요?**
A: 1. 타입 안전성: 필드 타입이 명시되어 IDE 자동완성 지원
   2. 불변성 지원: `frozen=True`로 불변 객체 생성 가능
   3. 자동 메서드: `__init__`, `__repr__`, `__eq__` 자동 생성
   4. 문서화: 필드 선언 자체가 문서 역할

**Q: to_dict() 메서드는 왜 필요한가요?**
A: Dash의 `dcc.Store`는 JSON 직렬화 가능한 딕셔너리만 저장할 수 있습니다.
   dataclass 객체를 딕셔너리로 변환하여 UI에 전달하기 위해 필요합니다.

### 3. `ugv_mon/data/mock_data.py` - 목 데이터 생성기

**역할**: 실제 패킷 캡처 없이도 UI 개발/테스트 가능하도록 시뮬레이션 데이터 제공

**구현 내용**:

```python
"""
Mock data generator for UGV-MON Dashboard.

Provides simulated data for UI development and testing when
actual VIC↔OCS traffic is not available.

This module will be replaced with actual Scapy capture and ICD
parsing in Day 2-3 of the development plan.
"""

import random
from datetime import datetime, timedelta
from typing import Dict, List
from .models import LogEntry, DeviceStatus, AvailabilitySegment
from ..config import config


class MockDataGenerator:
    """Generates mock dashboard data for UI testing."""
    
    def __init__(self):
        self._last_seq = 49195
        self._elapsed_time = 0
        self._logs_history: List[LogEntry] = []
        self._availability_segments: List[AvailabilitySegment] = [
            AvailabilitySegment(start_sec=0, end_sec=2700, is_up=True),
            AvailabilitySegment(start_sec=2700, end_sec=2850, is_up=False),
            AvailabilitySegment(start_sec=2850, end_sec=3600, is_up=True),
        ]
    
    def generate_initial_data(self) -> Dict:
        """Generate initial dashboard data for app startup."""
        now = datetime.now()
        
        # Generate initial chart data (60 points)
        chart_data = []
        for i in range(config.ui.max_chart_points):
            chart_data.append({
                "timestamp": (now - timedelta(seconds=60-i)).strftime("%H:%M:%S"),
                "pps": random.randint(900, 1100),
                "jitter": round(random.uniform(0.5, 2.5), 2),
            })
        
        # Generate initial log entries
        for i in range(15):
            log_time = now - timedelta(seconds=(15-i) * 2)
            self._logs_history.append(LogEntry(
                timestamp=log_time,
                sequence=self._last_seq + i,
                msg_code=f"0x{random.randint(0, 255):02X}",
                parse_ok=random.random() > 0.05,
                checksum_ok=random.random() > 0.03,
                mode=random.choice(["원격 주행 (REMOTE)", "수동", "대기"]),
                authority=random.choice(["OCS(운용통제기)", "근거리조종기", "없음"]),
                notes="네트워크 지터 감지 (12.5ms)" if i % 10 == 0 else "",
            ))
        
        self._last_seq += 14
        
        # Device statuses
        devices = [
            DeviceStatus("vic", "VIC", connected=True),
            DeviceStatus("rdc", "RDC", connected=True),
            # ... (10개 장치)
        ]
        
        return {
            "connected": True,
            "interface": config.network.interface,
            "filter": f"{config.network.source_port}→{config.network.dest_port}",
            "lastPacketTime": now.strftime("%H:%M:%S"),
            "capturePps": 1024,
            "filterPass": 99.9,
            "parseSuccess": 100.0,
            "checksumFail": 0.0,
            "packetLoss": 0,
            "availability5min": 99.98,
            "availability1hour": 99.99,
            "jitterP95": 2.1,
            "jitterP99": 2.4,
            "operationalMode": "원격 주행 (REMOTE)",
            "operationalAuthority": "OCS(운용통제기)",
            "drivingState": "전진/대기",
            "combinedData": chart_data,
            "devices": [d.to_dict() for d in devices],
            "emergencyStatus": {...},
            "availabilitySegments": [s.to_dict() for s in self._availability_segments],
        }
    
    def update_data(self, prev_data: Dict) -> Dict:
        """Update dashboard data for polling cycle."""
        now = datetime.now()
        
        # Add new chart data point (rolling window)
        new_point = {
            "timestamp": now.strftime("%H:%M:%S"),
            "pps": random.randint(900, 1100),
            "jitter": round(random.uniform(0.5, 2.5), 2),
        }
        chart_data = prev_data.get("combinedData", [])[1:] + [new_point]
        
        # Add new log entry
        self._last_seq += 1
        new_log = LogEntry(...)
        self._logs_history = [new_log] + self._logs_history[:config.ui.max_log_entries - 1]
        
        return {
            **prev_data,
            "lastPacketTime": now.strftime("%H:%M:%S"),
            "combinedData": chart_data,
            # ... (나머지 업데이트)
        }
    
    def get_logs(self, limit: int = 50) -> List[Dict]:
        """Get recent log entries for the event table."""
        return [log.to_dict() for log in self._logs_history[:limit]]
```

**코드 설명 (핵심 개념)**:

| 개념 | 설명 |
|------|------|
| `deque(maxlen=N)` | 크기가 N을 초과하면 반대쪽에서 자동 제거. 메모리 보호 |
| `random.randint(900, 1100)` | 실제 VIC↔OCS 통신의 PPS 범위와 유사하게 설정 |
| `timedelta(seconds=60-i)` | 과거 시간 생성. 차트 초기 데이터를 60개 포인트로 채움 |
| `prev_data.get("combinedData", [])[1:]` | 롤링 윈도우: 첫 번째 요소 제거 후 새 요소 추가 |

**Q&A**:

**Q: 왜 롤링 윈도우를 사용하나요?**
A: 무한정 데이터가 쌓이면 메모리 부족이 발생합니다.
   최근 N개만 유지하여 메모리 사용량을 제한합니다.
   예: `chart_data[1:] + [new_point]` → 가장 오래된 데이터 제거, 새 데이터 추가

**Q: 왜 랜덤 값을 사용하나요?**
A: 실제 패킷 캡처 없이도 UI 개발/테스트가 가능하도록 합니다.
   실제 값 범위(900-1100 pps)와 유사하게 설정하여 현실적인 테스트가 가능합니다.

**Q: `_last_seq`는 왜 필요한가요?**
A: 로그 엔트리의 시퀀스 번호를 연속적으로 생성하기 위함입니다.
   실제 패킷의 시퀀스 번호와 유사하게 동작하도록 시뮬레이션합니다.

### 4. `ugv_mon/app.py` - Dash 앱 팩토리

**역할**: Dash 앱 인스턴스를 생성하고 모든 컴포넌트를 연결

**구현 내용**:

```python
"""
UGV-MON Dash Application Module.

Creates and configures the Dash application instance with:
- External stylesheets (Inter font)
- Layout initialization
- Callback registration
"""

import dash
from .layouts.main_layout import create_main_layout
from .callbacks.update_callbacks import register_callbacks, get_data_generator
from .config import config


def create_app() -> dash.Dash:
    """
    Create and configure the Dash application.
    
    Returns:
        Configured Dash application instance
    """
    # Create Dash app
    app = dash.Dash(
        __name__,
        suppress_callback_exceptions=True,
        external_stylesheets=[
            "https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap",
        ],
        title=config.app.name,
    )
    
    # Expose server for WSGI deployment
    server = app.server
    
    # Initialize data generator and get initial data
    data_gen = get_data_generator()
    initial_data = data_gen.generate_initial_data()
    initial_logs = data_gen.get_logs(limit=50)
    
    # Set layout
    app.layout = create_main_layout(initial_data, initial_logs)
    
    # Register callbacks
    register_callbacks(app)
    
    return app


# Module-level app instance for imports
app = create_app()
server = app.server
```

**설명 및 근거**:
- **팩토리 패턴**: 테스트 시 여러 인스턴스 생성 가능
- **suppress_callback_exceptions**: 패턴 매칭 콜백 사용 시 필요
- **server 노출**: WSGI 배포 시 사용

### 5. `run.py` - 진입점

**역할**: 애플리케이션 실행 스크립트

**구현 내용**:

```python
#!/usr/bin/env python3
"""
UGV-MON Dashboard Entry Point.

Run this script to start the monitoring dashboard:
    python run.py
"""

import sys
import os
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

from ugv_mon.app import app
from ugv_mon.config import config


def main():
    """Run the UGV-MON dashboard server."""
    print(f"""
╔══════════════════════════════════════════════════════════════════╗
║                    UGV-MON Dashboard v{config.app.version}                      ║
║              VIC↔OCS Real-time Communication Monitor             ║
╠══════════════════════════════════════════════════════════════════╣
║  Server: http://{config.app.host}:{config.app.port}                              ║
║  Interface: {config.network.interface:<6}                                        ║
║  Filter: {config.network.source_port}→{config.network.dest_port}                                    ║
║  Poll Interval: {config.ui.poll_interval_ms}ms                                     ║
╚══════════════════════════════════════════════════════════════════╝
    """)
    
    app.run_server(
        debug=config.app.debug,
        host=config.app.host,
        port=config.app.port,
    )


if __name__ == "__main__":
    main()
```
