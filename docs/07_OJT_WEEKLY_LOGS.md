## 5주차: 데이터 분석 확장

### 주요 성과

#### Phase 1-6 완료

1. **pandas 하이브리드 전환**: 실시간 List + 분석시 DataFrame
2. **가용성 요약**: 10분/1시간 가용성 배지
3. **msg_code별 통계**: 탭 기반 UI (0x01, 0x10, 0x25, 0x40)
4. **연결 이력 로그**: 연결/끊김 시점 및 지속시간
5. **운용상태 전이 분석**: 모드 변경 이력
6. **비상정지 원인 통계**: 원인별 발생 횟수

#### 기술적 학습

- pandas DataFrame 최적화 (row-wise append 비효율성)
- Dash 선언적/반응형 프로그래밍
- 상태 변경 감지 패턴 (`_last_*` 변수 비교)

### 멘토 의견

> 기술 피드백에 대해 전공지식과 연계하여 사고하는 모습을 보임. 여러 데이터 분석 기법을 적극적으로 적용하고 구현함.
