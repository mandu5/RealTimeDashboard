### 1. `ugv_mon/analysis/jitter.py` - 지터 분석기

**역할**: 패킷 간 도착 시간 차이(Δt)를 분석하여 지터(Jitter) 통계 계산

**구현 내용**:

```python
"""
지터 분석 모듈

역할:
- 패킷 간 도착 시간 차이(Δt) 계산
- P95/P99 백분위수 계산
- 롤링 윈도우 기반 분석
"""

from collections import deque
from datetime import datetime
from typing import Optional, List

from ..config import config


class JitterAnalyzer:
    """
    지터 분석기
    
    패킷 간 도착 시간 차이(Δt)를 추적하여 지터 통계를 계산합니다.
    일반적으로 네트워크 모니터링에서 P95/P99 백분위수를 사용합니다.
    
    사용법:
        analyzer = JitterAnalyzer(window_size=1000)
        analyzer.record_packet(datetime.now())
        p95 = analyzer.get_percentile(95)
    """
    
    def __init__(self, window_size: int = 1000):
        """
        초기화
        
        Args:
            window_size: 롤링 윈도우 크기 (최근 N개 Δt 값만 유지)
        """
        self.window_size = window_size
        self._deltas: deque = deque(maxlen=window_size)  # Δt 값들 (ms)
        self._last_time: Optional[datetime] = None
        
    def record_packet(self, timestamp: datetime) -> Optional[float]:
        """
        패킷 도착 시간 기록
        
        Args:
            timestamp: 패킷 도착 시간
            
        Returns:
            이전 패킷과의 시간 차이 (ms), 첫 패킷이면 None
        """
        if self._last_time is None:
            # 첫 패킷
            self._last_time = timestamp
            return None
        
        # 시간 차이 계산 (밀리초)
        delta_ms = (timestamp - self._last_time).total_seconds() * 1000.0
        self._deltas.append(delta_ms)
        self._last_time = timestamp
        
        return delta_ms
    
    def get_percentile(self, percentile: int) -> float:
        """
        지정 백분위수 계산
        
        Args:
            percentile: 백분위수 (0-100)
            
        Returns:
            해당 백분위수 값 (ms)
        """
        if not self._deltas:
            return 0.0
        
        sorted_deltas = sorted(self._deltas)
        index = int(len(sorted_deltas) * percentile / 100)
        index = min(index, len(sorted_deltas) - 1)  # 인덱스 범위 체크
        
        return sorted_deltas[index]
    
    def get_metrics(self) -> dict:
        """
        대시보드용 메트릭 반환
        
        Returns:
            메트릭 딕셔너리 (P95, P99)
        """
        return {
            "jitterP95": round(self.get_percentile(95), 1),
            "jitterP99": round(self.get_percentile(99), 1),
        }
    
    def get_time_series(self, limit: int = None) -> List[float]:
        """
        최근 N개 델타 값 반환 (차트용)
        
        Args:
            limit: 반환할 최대 개수 (None이면 전체)
            
        Returns:
            Δt 값 리스트 (ms)
        """
        if limit is None:
            limit = config.ui.max_chart_points
        
        return list(self._deltas)[-limit:]
    
    def get_statistics(self) -> dict:
        """
        기본 통계 반환
        
        Returns:
            통계 딕셔너리 (min, max, mean, median)
        """
        if not self._deltas:
            return {
                "min": 0.0,
                "max": 0.0,
                "mean": 0.0,
                "median": 0.0,
            }
        
        sorted_deltas = sorted(self._deltas)
        n = len(sorted_deltas)
        
        return {
            "min": sorted_deltas[0],
            "max": sorted_deltas[-1],
            "mean": sum(self._deltas) / n,
            "median": sorted_deltas[n // 2],
        }
```

**설명 및 근거**:
- **Δt 계산**: 패킷 간 시간 차이로 네트워크 지터 측정
- **백분위수**: P95/P99는 네트워크 모니터링 표준 지표
- **롤링 윈도우**: 최근 N개 값만 유지하여 메모리 관리
- **밀리초 단위**: UI 표시를 위해 초가 아닌 밀리초 사용

### 2. `ugv_mon/analysis/loss.py` - 손실 추정기

**역할**: 시퀀스 번호 갭을 기반으로 패킷 손실 추정

**구현 내용**:

```python
"""
패킷 손실 추정 모듈

역할:
- 시퀀스 번호 갭 기반 손실 추정
- 8비트 롤오버(0-255) 처리
- 누적 손실 카운트
"""

from typing import Optional


class LossEstimator:
    """
    패킷 손실 추정기
    
    ICD 시퀀스 번호(8-bit, 0-255)를 사용하여 패킷 손실을 추정합니다.
    시퀀스 갭이 1보다 크면 손실이 발생한 것으로 간주합니다.
    
    사용법:
        estimator = LossEstimator()
        estimator.record_sequence(seq_num)
        loss_count = estimator.get_metrics()["packetLoss"]
    """
    
    def __init__(self, max_seq: int = 256):
        """
        초기화
        
        Args:
            max_seq: 최대 시퀀스 값 (8-bit이므로 256)
        """
        self.max_seq = max_seq
        self._last_seq: Optional[int] = None
        self._total_loss = 0  # 누적 손실 수
        self._total_packets = 0  # 총 처리된 패킷 수
        
    def record_sequence(self, seq: int) -> int:
        """
        시퀀스 번호 기록
        
        Args:
            seq: 현재 시퀀스 번호 (0-255)
            
        Returns:
            이번 패킷에서 감지된 손실 수
        """
        self._total_packets += 1
        
        if self._last_seq is None:
            # 첫 패킷
            self._last_seq = seq
            return 0
        
        # 갭 계산 (롤오버 처리)
        gap = self._seq_gap(self._last_seq, seq)
        
        # 갭이 1이면 정상, 1보다 크면 손실
        # 예: 10 -> 15면 5-1=4개 손실
        loss = max(0, gap - 1)
        self._total_loss += loss
        
        self._last_seq = seq
        return loss
    
    def _seq_gap(self, prev: int, curr: int) -> int:
        """
        롤오버를 고려한 시퀀스 갭 계산
        
        Args:
            prev: 이전 시퀀스 번호
            curr: 현재 시퀀스 번호
            
        Returns:
            갭 값 (정상: 1, 손실: >1)
        """
        if curr >= prev:
            # 정상 순차 진행
            return curr - prev
        else:
            # 롤오버 발생 (예: 255 -> 0)
            return (self.max_seq - prev) + curr
    
    def get_metrics(self) -> dict:
        """
        대시보드용 메트릭 반환
        
        Returns:
            메트릭 딕셔너리 (packetLoss, totalPackets)
        """
        return {
            "packetLoss": self._total_loss,
            "totalPackets": self._total_packets,
        }
    
    def reset(self) -> None:
        """카운터 리셋 (테스트용)"""
        self._last_seq = None
        self._total_loss = 0
        self._total_packets = 0
```

**설명 및 근거**:
- **시퀀스 갭**: ICD 규격에 따라 timestamp의 마지막 1 byte가 시퀀스
- **롤오버 처리**: 8-bit이므로 255 다음에 0으로 순환
- **손실 추정**: 갭이 1보다 크면 손실로 간주 (예: 10→15면 4개 손실)
- **누적 카운트**: 전체 실행 기간 동안의 총 손실 추적

```python
# test_jitter.py
from ugv_mon.analysis.jitter import JitterAnalyzer
from datetime import datetime, timedelta

def test_jitter_calculation():
    """지터 계산 테스트"""
    analyzer = JitterAnalyzer(window_size=100)
    
    now = datetime.now()
    
    # 정상 패킷 (1ms 간격 시뮬레이션)
    for i in range(100):
        analyzer.record_packet(now + timedelta(milliseconds=i))
    
    metrics = analyzer.get_metrics()
    print(f"P95: {metrics['jitterP95']}ms")
    print(f"P99: {metrics['jitterP99']}ms")
    
    assert metrics['jitterP95'] > 0
    assert metrics['jitterP99'] >= metrics['jitterP95']
```

### 2. 손실 추정 테스트

```python
# test_loss.py
from ugv_mon.analysis.loss import LossEstimator

def test_loss_estimation():
    """손실 추정 테스트"""
    estimator = LossEstimator()
    
    # 정상 시퀀스 (연속)
    for seq in range(10):
        loss = estimator.record_sequence(seq)
        assert loss == 0 if seq > 0 else True
    
    # 손실 시뮬레이션 (10 -> 15, 4개 손실)
    loss = estimator.record_sequence(15)
    assert loss == 4
    
    metrics = estimator.get_metrics()
    assert metrics['packetLoss'] == 4

def test_rollover():
    """롤오버 처리 테스트"""
    estimator = LossEstimator()
    
    # 254 -> 0 (롤오버, 정상)
    estimator.record_sequence(254)
    loss = estimator.record_sequence(0)
    assert loss == 1  # 정상 (롤오버)
    
    # 254 -> 2 (롤오버 + 손실)
    estimator.reset()
    estimator.record_sequence(254)
    loss = estimator.record_sequence(2)
    assert loss == 4  # 3개 손실 (255, 0, 1)
```

```bash
# 지터 + 손실 통합 테스트
sudo python -c "
from ugv_mon.capture.sniffer import PacketSniffer
from ugv_mon.parser.icd_parser import ICDParser
from ugv_mon.analysis.jitter import JitterAnalyzer
from ugv_mon.analysis.loss import LossEstimator
from datetime import datetime

sniffer = PacketSniffer('lo')
parser = ICDParser()
jitter = JitterAnalyzer()
loss = LossEstimator()

sniffer.start()

import time
start_time = time.time()
while time.time() - start_time < 60:  # 1분간
    packet = sniffer.get_packet(timeout=0.5)
    if packet:
        now = datetime.now()
        jitter.record_packet(now)
        
        payload = bytes(packet['UDP'].payload)
        result = parser.parse(payload)
        if result.header:
            loss.record_sequence(result.header.sequence)

jitter_metrics = jitter.get_metrics()
loss_metrics = loss.get_metrics()

print(f'Jitter P95: {jitter_metrics[\"jitterP95\"]}ms')
print(f'Jitter P99: {jitter_metrics[\"jitterP99\"]}ms')
print(f'Packet Loss: {loss_metrics[\"packetLoss\"]}')

sniffer.stop()
"
```
